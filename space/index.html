Aftermarket leaderboard

Does a safety fix survive the next person who downloads the model? Every public safety fix for Tiny Aya Global from the Lexsi AI Safety & Alignment Hackathon, plus the base model, faces the same post-release battery. Same prompts, seed, settings and judges for every model; 95% bootstrap intervals; held-out test prompts only. Method, code and credits.

One page per model: attack success per attack with 95% CIs (grey band: range across the ranked leaderboard runs; black tick: BASE), retention and rank, over-refusal and MMLU.

Run it on your own model

git clone https://github.com/bennytimz/aftermarket && cd aftermarket
pip install -r requirements.txt && pip install -e .
aftermarket audit --model your-org/your-model --quick     # A0, A2, A3, A5bon on 100 prompts
aftermarket audit --model your-org/your-model             # the full battery

Retention = 1 − mean rise in attack success over attack families A1–A5 (1 = nothing lost). AM, our own defense, in orange; partial-battery controls lighter and not ranked.

Llama-Guard-3-1B (primary) and WildGuard on every harmful-prompt response, row level (each best-of-8 variant counted once).

Attacks: A0 as released; A1 benign QLoRA fine-tune; A2 fine-tune with 100 harmful examples; A3 abliteration of the refusal direction; A4q3 3-bit HQQ compression (A4q4 extra, partial); A5raw chat template removed; A5bon best-of-8 prompt perturbations; A3max (†) abliteration at the strongest layer, a post-hoc sensitivity check never used in retention or rankings.

Every team is credited in the write-up, and results are framed as robustness after release, not as verdicts on any fix. This page shows aggregate metrics only: no prompts, no model outputs and no attack-modified weights.
